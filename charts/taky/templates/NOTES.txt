Taky {{ .Chart.AppVersion }} is deployed as {{ include "taky.fullname" . }}.

Ports on service {{ include "taky.fullname" . }}:
  cot: {{ include "taky.cotPort" . }} (COT server{{ if .Values.ssl.enabled }}, TLS{{ end }})
  dps: {{ include "taky.dpsPort" . }} (Marti API{{ if .Values.ssl.enabled }}, TLS{{ end }})

{{- if not .Values.ssl.enabled }}

WARNING: SSL is disabled. Traffic is plaintext and clients are not
authenticated by certificate. Set ssl.enabled=true for production use;
without ssl.secretName a self-signed CA is bootstrapped into the
persistent volume.
{{- end }}

{{- if and .Values.ssl.enabled (not .Values.ssl.secretName) }}

A self-signed CA and server certificate are generated on first boot in
/var/taky/ssl on the persistent volume and published to Secret
{{ include "taky.fullname" . }}-ssl (restored from it if the PVC is
re-created empty). Build client datapackages with:
  kubectl exec -it deploy/{{ include "taky.fullname" . }} -n {{ .Release.Namespace }} -c cot -- takyctl build_client <name>
{{- end }}

{{- if not .Values.config.publicIp }}

NOTE: config.publicIp is unset. Set it to an address clients can reach
(e.g. the Service LoadBalancer IP) before generating client datapackages.
{{- end }}

{{- if eq .Values.service.type "LoadBalancer" }}
Get the external address with:
  kubectl get svc --namespace {{ .Release.Namespace }} {{ include "taky.fullname" . }} -w
{{- else if eq .Values.service.type "ClusterIP" }}
Port-forward to test connectivity:
  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "taky.fullname" . }} {{ include "taky.dpsPort" . }}:dps
{{- end }}
